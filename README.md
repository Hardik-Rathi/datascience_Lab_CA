# ✈️ Air Travel Data Science Analysis (Lab CA)

A three-phase data science project analyzing air travel passenger volume, fare pricing, route distances, and seasonal demand trends.

---

## 📌 Project Overview

This repository contains the complete analytical workflow for the Air Travel Data Science Mini Competition:
* **Phase 1 – Data Handling & Cleaning:** Preprocessing raw air travel dataset (`export.csv`) into a cleaned format (`export_phase1_cleaned.csv`).
* **Phase 2 – Statistical Analysis:** Computing statistical measures including central tendency, measures of dispersion, skewness, kurtosis, IQR outlier detection, correlations, and YoY growth rates.
* **Phase 3 – Data Visualization:** Building distribution histograms, outlier boxplots, yearly time-series trends, quarterly demand charts, and bivariate correlation scatter plots.
